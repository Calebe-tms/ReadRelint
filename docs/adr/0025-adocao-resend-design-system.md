# ADR-0025: Adoção do Resend Design System (`Design.md`)

- Status: Aceita
- Data: não registrada

## Contexto
A interface web carecia de uma linguagem visual coesa e profissional; adotar um design system de referência (inspirado no Resend) dá uma base consistente de cores, tipografia e bordas para toda a aplicação.

## Decisão
Reconstrução do tema CSS da aplicação Web com base nas diretrizes do `Design.md`: Canvas preto puro (`#000000`), hairlines translúcidas (`rgba(255,255,255,0.14)`), fontes Inter/Mono.

## Consequências
Traz consistência visual imediata e uma identidade de alto contraste adequada a um painel de monitoramento. Fixa, porém, decisões estéticas específicas (paleta, fontes) que futuras mudanças de marca precisarão revisitar deliberadamente.
