# ADR-0027: Foco na Experiência Desktop Nativa (Tkinter / CustomTkinter)

- Status: Aceita
- Data: não registrada

## Contexto
Operações de sistema operacional como seleção de pastas e monitoramento contínuo de diretórios são mais naturais e responsivas em uma aplicação desktop nativa do que emuladas via navegador.

## Decisão
Decisão de manter a interface Desktop nativa para gerenciamento do motor local e monitoramento de pastas.

## Consequências
Mantém uma experiência de usuário fluida para tarefas de sistema operacional, mas perpetua a necessidade de manter dois frontends distintos (desktop e web) em paralelo.
