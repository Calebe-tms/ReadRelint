# ADR-0028: Tema Dark Slate Neutro para UI Desktop

- Status: Aceita
- Data: não registrada

## Contexto
O tema anterior da interface desktop carregava subtons azulados que destoavam da identidade visual mais neutra buscada para o painel, além de não oferecer contraste ideal de leitura.

## Decisão
Eliminação completa de subtons de azul na interface CustomTkinter em favor de tons de carvão neutros (`#121212`, `#18181b`, `#27272a`) com acentos em Verde Esmeralda (`#10b981`), Teal (`#0d9488`) e Âmbar (`#d97706`), garantindo alto contraste de texto branco (`#ffffff`).

## Consequências
Melhora a legibilidade e a coerência visual da interface desktop com uma paleta neutra e de alto contraste. É uma mudança puramente estética, sem impacto funcional no sistema.
