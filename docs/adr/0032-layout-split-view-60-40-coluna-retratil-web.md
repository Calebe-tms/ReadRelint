# ADR-0032: Layout Split View 60/40 com Coluna Retrátil na Web

- Status: Aceita
- Data: não registrada

## Contexto
A tela de monitoramento web precisa exibir simultaneamente controles/logs operacionais e a lista de relatórios processados, mas usuários focados em uma das duas frentes se beneficiam de poder expandir aquela área.

## Decisão
Divisão da view de monitoramento em 60% controle/logs e 40% lista de relatórios, com funcionalidade retrátil para expandir a área de controle para 100%.

## Consequências
Dá flexibilidade ao usuário para priorizar a área que interessa no momento, sem perder acesso rápido à outra. Aumenta a complexidade de layout responsivo da tela de monitoramento.
